SAVANNA BREW CAFE WEBSITE
=========================

PROJECT CONTENTS
- index.html       Home page
- about.html       About Us page
- menu.html        Menu page with three price tables
- gallery.html     Eight-image responsive gallery
- contact.html     Contact details, opening hours and reservation form
- css/style.css    One shared external stylesheet
- images/          Local SVG illustrations used as image assets

HOW TO RUN
1. Extract the ZIP file into a folder.
2. Open the savanna-brew folder.
3. Double-click index.html, or open it in a web browser.
4. Use the navigation links to visit all five pages.

IMPORTANT NOTES
- All image assets are included locally as SVG illustrations. They are intentional,
  offline-friendly placeholders and can be replaced with suitable café photographs.
  Keep the filenames and paths unchanged when replacing them, or update the HTML.
- The reservation form uses a mailto action as a basic HTML-only demonstration.
  A production reservation system needs a server-side form handler or booking service.
- Google Fonts are loaded online; Georgia and Arial fallback fonts are provided.
- The website uses HTML5 and CSS only. No JavaScript or CSS framework is used.
